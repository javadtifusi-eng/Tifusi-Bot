## 📋 معرفی

**Tifusi Bot** یک ربات فروشگاهی کامل برای فروش اشتراک VPN است که به‌صورت خودکار فقط با **[Tifusi Panel](https://github.com/javadtifusi-eng/Tifusi-Panel)** کار می‌کند و این ۴ سرویس را می‌فروشد:

- 🌐 **Xray** (VLESS / VMess / Trojan)
- 🔒 **WireGuard** (وقتی به Tifusi Panel اضافه شود و ادمین برایش گروه انتخاب کند)
- 🛡 **IKEv2**
- 🔗 **L2TP**

مشتری پلن و سرویس را انتخاب می‌کند و یوزرنیم دلخواهش را می‌فرستد؛ باقی‌اش با ربات: پرداخت، ساخت کاربر روی خلوت‌ترین پنل، تحویل **کد اپ**، **لینک اشتراک** و **QR code**، تمدید و بازگشت وجه — همه خودکار. ⚡

> 🔑 **بدون رمز!** مشتری رمز وارد نمی‌کند؛ پنل برای هر کاربر یک لینک اشتراک و یک کد اپ (به شکل `CODE@آدرس-پنل`) صادر می‌کند. کد در اپ **[Tifusi VPN](https://github.com/javadtifusi-eng/Tifusi-VPN)** (اندروید / ویندوز) وارد می‌شود و روی آیفون لینک اشتراک در Safari باز می‌شود. با تمدید، کد و لینک عوض نمی‌شوند.

### 🧩 پنل پشتیبانی‌شده

| پنل | سرویس‌ها | آنچه مشتری دریافت می‌کند |
|---|---|---|
| **[Tifusi Panel](https://github.com/javadtifusi-eng/Tifusi-Panel)** | Xray / WireGuard / IKEv2 / L2TP | کد اپ، لینک اشتراک، QR code و لینک دانلود اپ Tifusi VPN (اندروید و ویندوز) |

**افزودن پنل:** مدیریت پنل‌ها ← ➕ افزودن پنل ← نام، آدرس پنل (مثلاً `https://panel.example.com`)، یوزرنیم و پسورد ادمین پنل. ربات اتصال را تست می‌کند و گروه‌های پنل را می‌خواند؛ بعد برای هر ۴ سرویس یک **گروه** یا «روی این پنل فروخته نشود» را انتخاب می‌کنید و در آخر موقعیت و سقف کاربر.

**نگاشت سرویس ← گروه:** گروه پنل تعیین می‌کند کاربر به کدام سرورها دسترسی دارد؛ سروری که در هیچ گروهی نیست برای همه است. اگر پنل گروهی ندارد، گزینه‌ی «سرورهای عمومی» نشان داده می‌شود. به مشتری فقط سرویس‌هایی نمایش داده می‌شود که حداقل یک پنل فعال با ظرفیت خالی برایشان گروه دارد (پس WireGuard تا وقتی گروهی برایش انتخاب نشود مخفی می‌ماند). نگاشت هر زمان از جزئیات پنل ← «🧩 انتخاب گروه سرویس‌ها» قابل تغییر است.

> ♻️ **ارتقا از نسخه‌های قبلی:** پنل‌ها و سفارش‌های قدیمی (vpn-ui و ...) از دیتابیس پاک نمی‌شوند؛ پنل‌ها با برچسب «قدیمی (غیرفعال)» نمایش داده می‌شوند و در فروش و چک سلامت استفاده نمی‌شوند، و سفارش‌های قدیمی فقط قابل مشاهده‌اند (تمدید و حذف غیرفعال است و به مشتری پیشنهاد خرید جدید داده می‌شود).

## 🚀 نصب با یک خط (پیشنهادی)

روی سرور اوبونتو (۲۰.۰۴ به بالا) به‌صورت root این دستور را بزنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/javadtifusi-eng/Tifusi-Bot/main/install.sh)
```

> ⚠️ این لینک عمومی است — همه می‌توانند بدون لاگین نصب کنند.

## 🔧 نصب دستی

```bash
# ۱) پیش‌نیازها
apt update && apt install -y python3 python3-pip
pip3 install python-telegram-bot[job-queue] requests qrcode pillow --break-system-packages

# ۲) دانلود ربات
curl -Ls https://raw.githubusercontent.com/javadtifusi-eng/Tifusi-Bot/main/bot.py -o /root/bot.py

# ۳) تنظیم توکن و ادمین (خطوط ابتدای فایل)
nano /root/bot.py
# BOT_TOKEN = "توکن از @BotFather"
# ADMIN_ID = آیدی عددی از @userinfobot

# ۴) اجرا
python3 /root/bot.py
```

## ⚙️ پیش‌نیازهای Tifusi Panel

ربات برای ساخت اکانت به **[Tifusi Panel](https://github.com/javadtifusi-eng/Tifusi-Panel)** نیاز دارد. روی هر پنل این موارد را چک کنید:

- [ ] پنل نصب است و آدرسش (ترجیحاً HTTPS) از سرور ربات در دسترس است
- [ ] یوزرنیم/پسورد ادمین پنل برای افزودن در بخش «پنل‌ها» ربات
- [ ] هسته‌ها و سرورهای سرویس‌هایی که می‌فروشید (Xray / IKEv2 / L2TP) روی پنل تعریف شده‌اند
- [ ] (اختیاری) برای هر سرویس یک **گروه** در پنل ساخته‌اید تا مشخص شود کاربرانش به کدام سرورها وصل شوند؛ بدون گروه همه‌ی سرورها عمومی‌اند

## ❓ سوالات متداول

**رباتم ارور داد، VPN کاربرها برای لحظه‌ای قطع شد. چرا؟**
پنل vpn-ui بعد از هر تغییر کلاینت، Xray را ری‌استارت می‌کند (معماری خود پنل است) و ترافیک ۱ تا ۲ ثانیه قطع می‌شود. نسخه ۴.۰ تعداد درخواست‌ها را حداقل کرده تا این وقفه کمترین باشد.

**توکن رباتم لو رفت؟**
در @BotFather دستور `/revoke` را بزنید و توکن جدید را از منوی `tifusi bot` (گزینه ۳) وارد کنید.
