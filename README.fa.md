## 📋 معرفی

**Tifusi Bot** یک ربات فروشگاهی کامل برای فروش اشتراک VPN است که فقط با **[Tifusi Panel](https://github.com/javadtifusi-eng/Tifusi-Panel)** کار می‌کند.

مشتری «خرید اشتراک» را می‌زند، سرویس (پروتکل) و بعد پلن را انتخاب می‌کند و یوزرنیم دلخواهش را می‌فرستد؛ باقی‌اش با ربات: پرداخت، ساخت کاربر روی خلوت‌ترین پنل، تحویل **شناسه**، **لینک اشتراک** و **QR code**، یادآوری انقضا، تمدید و بازگشت وجه — همه خودکار. ⚡

> 🔑 **رمز فقط جایی که لازم است.** پنل برای هر کاربر یک لینک اشتراک و یک شناسه (به شکل `javad7KQ4MP9X@آدرس-پنل`) صادر می‌کند. در اپ اندروید **[Tifusi VPN](https://github.com/javadtifusi-eng/Tifusi-VPN)** شناسه در تب «سرورها» وارد می‌شود یا QR با «اسکن بارکد» اسکن می‌شود؛ روی آیفون لینک اشتراک در Safari باز می‌شود. فقط خریداران IKEv2 و L2TP بعد از یوزرنیم رمز می‌گیرند — رمز دلخواه می‌فرستند یا «رمز تصادفی» را می‌زنند. با تمدید، شناسه، لینک، QR و رمز عوض نمی‌شوند.

### 📡 پروتکل‌ها مستقیم از پنل خوانده می‌شوند

ربات همه‌ی سرویس‌ها را می‌شناسد، ولی **فقط سرویسی را به مشتری نشان می‌دهد که روی پنل برایش هاست تعریف شده باشد**:

| سرویس در ربات | پروتکل‌های پنل |
|---|---|
| 🌐 Xray | VLESS / VMess / Trojan / Shadowsocks |
| ⚡ Hysteria2 | Hysteria2 |
| 🛡 IKEv2 | IKEv2 |
| 🔗 L2TP | L2TP |
| 🔒 WireGuard | WireGuard (وقتی به پنل اضافه شود) |

- اگر روی پنل فقط IKEv2 دارید، در ربات فقط IKEv2 فروخته می‌شود.
- پروتکل جدیدی روی پنل ساختید؟ در ربات «🖥 مدیریت پنل‌ها ← پنل ← 🔄 بررسی اتصال» را بزنید (هر ۵ دقیقه هم خودکار بررسی می‌شود) تا به فروش اضافه شود. هاستی را حذف کردید، سرویسش خودکار از فروش خارج می‌شود و به ادمین اطلاع داده می‌شود.
- کاربری که مثلاً IKEv2 می‌خرد **فقط** به IKEv2 دسترسی می‌گیرد، نه همه‌ی پروتکل‌ها.

**افزودن پنل:** مدیریت پنل‌ها ← ➕ افزودن پنل ← نام، آدرس پنل (مثلاً `https://panel.example.com`)، یوزرنیم و پسورد ادمین پنل. ربات اتصال را تست می‌کند، پروتکل‌ها و گروه‌های پنل را می‌خواند؛ بعد برای هر سرویسِ موجود یک **گروه** یا «روی این پنل فروخته نشود» را انتخاب می‌کنید و در آخر موقعیت و سقف کاربر.

**نگاشت سرویس ← گروه:** گروه پنل تعیین می‌کند کاربر به کدام سرورها دسترسی دارد؛ سروری که در هیچ گروهی نیست برای همه است. نگاشت هر زمان از جزئیات پنل ← «🧩 انتخاب گروه سرویس‌ها» قابل تغییر است.

> ♻️ **ارتقا از نسخه‌های قبلی:** با اولین اجرا، پنل‌های غیر Tifusi نسخه‌های خیلی قدیمی (vpn-ui و ...) از ربات حذف و سفارش‌هایشان «بایگانی» می‌شوند (در آمار می‌مانند). کاربران، کیف پول‌ها، پلن‌ها و سفارش‌های Tifusi Panel دست‌نخورده می‌مانند. قبل از ارتقا از «💾 بکاپ» یک نسخه بگیرید.

## 🚀 نصب با یک خط (پیشنهادی)

روی سرور اوبونتو (۲۰.۰۴ به بالا) به‌صورت root این دستور را بزنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/javadtifusi-eng/Tifusi-Bot/main/install.sh)
```

> ⚠️ این لینک عمومی است — همه می‌توانند بدون لاگین نصب کنند.

### 📖 منوی مدیریت نصب‌کننده

بعد از نصب، هر وقت در ترمینال بزنید `tifusi bot` این منو برمی‌گردد (`tifusi panel` منوی Tifusi Panel و `tifusi app` آخرین نسخه‌ی اپ Tifusi VPN را نشان می‌دهد):

```
1) Install / Reinstall bot
2) Update bot (from GitHub — settings preserved)
3) Edit bot token
4) Edit admin ID
5) Restart bot
6) Bot status
7) Live logs (exit: Ctrl+C)
8) Uninstall bot
0) Exit
```

## 🔧 نصب دستی

```bash
# ۱) پیش‌نیازها
apt update && apt install -y python3 python3-pip
pip3 install python-telegram-bot[job-queue] requests qrcode pillow --break-system-packages

# ۲) دانلود ربات
curl -Ls https://raw.githubusercontent.com/javadtifusi-eng/Tifusi-Bot/main/bot.py -o /root/bot.py

# ۳) تنظیم توکن و ادمین (خطوط ابتدای فایل)

# BOT_TOKEN = "توکن از @BotFather"

# ۴) اجرا
python3 /root/bot.py
```

## ⚙️ پیش‌نیازهای Tifusi Panel

ربات برای ساخت اکانت به **[Tifusi Panel](https://github.com/javadtifusi-eng/Tifusi-Panel)** نیاز دارد. روی هر پنل این موارد را چک کنید:

- [ ] پنل نصب است و آدرسش (ترجیحاً HTTPS با گواهی معتبر) از سرور ربات در دسترس است
- [ ] برای ربات در پنل **یک ادمین جدا** بسازید (تنظیمات ← ادمین‌ها) با دسترسی **کاربران** و **گروه‌ها** — از حساب مالک پنل استفاده نکنید
- [ ] هسته‌ها و **هاست‌های** سرویس‌هایی که می‌فروشید روی پنل تعریف شده‌اند (هر پروتکلی هاست داشته باشد در ربات فروخته می‌شود)
- [ ] (اختیاری) برای هر سرویس یک **گروه** در پنل ساخته‌اید تا مشخص شود کاربرانش به کدام سرورها وصل شوند؛ بدون گروه همه‌ی سرورها عمومی‌اند

## 💾 بکاپ و بازگردانی

- **پنل مدیریت ← 💾 بکاپ ← 📥 دریافت بکاپ الان:** یک فایل `.db` شامل کاربران، موجودی کیف پول‌ها، سفارش‌ها، رسیدها، پنل‌ها، پلن‌ها و تنظیمات.
- **بکاپ خودکار:** هر شب ساعت ۳ برای ادمین اصلی (قابل خاموش کردن). اگر در «⚙️ تنظیمات عمومی» آیدی «کانال بکاپ» را وارد کنید، آنجا هم فرستاده می‌شود — ربات باید در آن کانال ادمین باشد.
- **بازگردانی:** فقط ادمین اصلی: 💾 بکاپ ← ♻️ بازگردانی ← فایل را بفرستید ← تایید. نسخه‌ی قبلی کنار دیتابیس با پسوند `.before-restore` نگه داشته می‌شود.

## ❓ سوالات متداول

**بعد از خرید، VPN کاربران برای یک لحظه قطع شد. چرا؟**
با ساخت یا تغییر هر کاربر، Tifusi Panel کانفیگ نودها را دوباره همگام می‌کند و ممکن است اتصال‌ها یک لحظه قطع و وصل شوند. ربات برای هر خرید فقط همان یک تغییر را روی پنل انجام می‌دهد.

**پروتکل جدید روی پنل اضافه کردم ولی در ربات نیامد.**
در ربات: 🖥 مدیریت پنل‌ها ← پنل ← 🔄 بررسی اتصال. اگر آن پروتکل را قبلاً «روی این پنل فروخته نشود» زده بودید، از «🧩 انتخاب گروه سرویس‌ها» دوباره فعالش کنید.

**ربات چند کاربر را همزمان جواب می‌دهد؟**
پیام‌های کاربران مختلف همزمان پردازش می‌شوند و ورود به پنل برای هر خرید تکرار نمی‌شود؛ پس یک خرید کند بقیه را منتظر نمی‌گذارد. گلوگاه اصلی سرعت پنل و همگام‌سازی نودهاست، نه ربات.

**توکن رباتم لو رفت؟**
در @BotFather دستور `/revoke` را بزنید و توکن جدید را از منوی `tifusi bot` (گزینه ۳) وارد کنید.
