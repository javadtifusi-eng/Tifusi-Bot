# رابط وب Claudex

نسخهٔ قابل بازبینی فایل‌های استاتیک مینی‌اپ خصوصی مالک؛ بک‌اند، تنظیمات ورود و دادهٔ گفتگو در این پوشه نیست.

رابط غروب با تب‌های خانه، Claude، Codex، SSH و تنظیمات. فایل‌های app.js/enhance.js همان پروتکل API و ترمینال موجود را نگه می‌دارند؛ workspace.js و workspace.css ظاهر و مسیریابی تب‌های اصلی را اضافه می‌کنند.

فضای امن تلگرام روی کل app اعمال می‌شود؛ نه فقط هدر. صفحهٔ خانه هم فاصلهٔ لازم دارد، با fallback برای گزارش نشدن insets در fullscreen. نوار موقت DEBUG-FS حذف شده است.

استقرار: بعد از بکاپ پوشه static، دارایی‌های جدید و app.js را کپی و index.html را آخر جایگزین کنید. مسیر عملیاتی /root/claudex/static است؛ restart لازم نیست. تغییرات موجودِ هم‌زمان را پیش از کپی بررسی کنید. backend و اطلاعات ورود را کپی نکنید.

اعتبارسنجی: node --check و Playwright روی عرض 320،390،1280؛ fullscreen با/بدون گزارش inset، جابه‌جایی دستیار/حفظ پیش‌نویس، کپی کد، جلسه‌ها و تنظیمات، SSH و کیبورد. تست‌ها API ساختگی دارند و اتصال یا فرمان SSH واقعی اجرا نمی‌کنند. تجربهٔ نهایی تلگرام آیفون نیازمند تأیید مالک است.

دارایی غروب همان تصویر تأییدشدهٔ مینی‌اپ فروش است؛ لوگوهای اصلی دستیارها و تیفوسی حفظ شده‌اند. نسخه cache: workspace25.
